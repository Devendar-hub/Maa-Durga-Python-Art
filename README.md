# 🙏 Maa Durga Python Art

## 📌 About the Project
Maa Durga Python Art is a creative Python project that uses programming and graphics to draw artistic representations of Goddess Durga. This project combines Python coding with creativity to create a devotional artwork.

## 🎯 Project Objective
The main objective of this project is to explore Python graphics and demonstrate how programming can be used to create creative and devotional digital art.

## 🛠️ Technologies Used
- **Programming Language:** Python
- **Graphics:** Python graphics/drawing libraries
- **Editor:** Visual Studio Code

## 📂 Project Structure
```text
Maa-Durga-Python-Art/
├── durga.py
├── durga.jpg
└── README.md
```

## ⚙️ How to Run the Project

1. Install Python on your computer.
2. Clone or download this repository.
3. Open the project folder in Visual Studio Code.
4. Open the terminal and run:

```bash
python durga.py
```

5. Enjoy the Maa Durga artwork!
